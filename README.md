### 🚀 Featured Production Engineering Projects

#### 1. [Local RAG Document Pipeline](https://github.com/irtazirfan08-source/local-rag-document-pipeline)
* **Domain:** Generative AI & Offline Retrieval Systems
* **Stack:** LangChain, ChromaDB, SentenceTransformers, Ollama (LLaMA 3.2:3b)
* **Overview:** Fully local, privacy-first document ingestion and retrieval system. Extracts and chunks `.pdf`, `.docx`, and `.txt` documents, generates 384-dimensional dense embeddings (`all-MiniLM-L6-v2`), and performs grounded semantic question-answering with strict anti-hallucination guardrails and source citations.

#### 2. [Real-Time Predictive Analytics API](https://github.com/irtazirfan08-source/predictive-analytics-api)
* **Domain:** Asynchronous ML Microservices & Containerization
* **Stack:** FastAPI, Scikit-Learn, Docker, Pydantic v2, Uvicorn
* **Overview:** Production inference microservice serving serialized Scikit-Learn pipelines. Implements sub-millisecond single and batch prediction endpoints, strict schema validation, structured error handling, and multi-stage non-root Docker deployment with health check probes.

#### 3. [Automated ML Monitoring & Data Drift Detector](https://github.com/irtazirfan08-source/ml-drift-monitor)
* **Domain:** Production MLOps & Statistical Quality Assurance
* **Stack:** SciPy, Kolmogorov-Smirnov Tests, Wasserstein Distance, Jinja2
* **Overview:** Automated data quality and distribution shift monitoring engine. Detects Covariate Shift and Concept Shift across continuous feature spaces, exports structured JSON audit logs, renders dark-mode HTML visual dashboards, and triggers automated pipeline retraining alerts.

#### 4. [Football Vision Engine](https://github.com/irtazirfan08-source/football_vision_engine)
* **Domain:** Computer Vision & Object Tracking
* **Stack:** OpenCV, PyTorch, YOLO, ByteTrack
* **Overview:** Computer vision analytics pipeline for tracking players, referees, and ball trajectories in sports broadcast video streams, generating real-time speed and spatial heatmaps.
